JoyBot 数据流 Demo 链路

对照 temporal-learn 当前源码。一次成功的 Run 按下面两段时序走完。Temporal 的启动、历史、任务队列、Query 和 Signal 是真实调用。控制面账本、MySQL、模型和列目录只写在日志里。

业务 Run 固定是 42，Thread 是 88001。Workflow ID 默认是 joybot/run/当前毫秒，和业务 Run ID 不是同一个值。
预发正式 namespace 是 joybot-pre。本机开发服务使用 default，地址 127.0.0.1:7233，界面 http://127.0.0.1:8233。

从输入到等待工具回执

sequenceDiagram
  autonumber
  participant D as demo-client
  participant F as Frontend
  participant H as History
  participant M as Matching
  participant W as workflow-worker
  participant B as business 队列
  participant A as agent-worker

  Note over D: 扮演页面、控制面、outbox、设备
  D->>D: 生成 WorkflowId joybot/run/毫秒
  D->>D: 记录输入「列出我云电脑桌面上的文件」
  D->>D: 模拟事务 run=42 execution=7 outbox=9001
  D->>F: StartWorkflowExecution workflow-type-name
  Note over D,F: 队列 joybot-workflow-v2，REJECT_DUPLICATE
  F->>H: 写入 WorkflowExecutionStarted
  H->>H: 再写 WorkflowTaskScheduled
  H->>M: 登记 Workflow Task
  F-->>D: 返回 temporalRunId
  M->>W: Poll 取走 Workflow Task
  W->>W: 回放历史，phase=ADMISSION
  W->>B: v2BeginExecution
  Note over B: BusinessActivitiesImpl，模拟准入
  B-->>W: execution=7 controlVersion=3
  W->>W: phase=MODEL_TURN
  W->>A: modelTurn stepSeq=1
  Note over A: ModelActivitiesImpl，只提议 list_dir
  A-->>W: disposition=TOOLS tool-100
  W->>B: v2CommitTurn
  B-->>W: 模拟提交 step=1
  W->>W: phase=DISPATCH
  W->>B: v2DispatchTools
  B-->>W: 模拟命令 cmd-100，尚无回执
  W->>B: markWaitingForToolSignal
  W->>W: phase=WAIT_TOOL
  Note over W: Workflow.await signal-name kind=TOOL，限时 30 秒

回执唤醒之后直到结束

sequenceDiagram
  autonumber
  participant D as demo-client
  participant F as Frontend
  participant H as History
  participant M as Matching
  participant W as workflow-worker
  participant B as business 队列
  participant A as agent-worker

  loop 每 200 毫秒，最多 30 秒
    D->>F: Query phase
    F->>W: 由等待中的 Workflow 回答
    W-->>D: phase
  end
  D->>D: 模拟 Host 执行 list_dir
  D->>D: 模拟回执事务 outbox=9002
  D->>F: Signal signal-name kind=TOOL
  Note over D,F: operationId=tool-100，文件为值班表.xlsx 与笔记.txt
  F->>H: 追加 WorkflowExecutionSignaled
  H->>M: 再登记一个 Workflow Task
  M->>W: Poll 取走任务并回放
  W->>W: 命中 TOOL，phase=MODEL_TURN
  W->>A: modelTurn stepSeq=2
  Note over A: 先应用 tool-100 的回执
  A-->>W: disposition=FINAL
  W->>B: v2CommitTurn
  B-->>W: 模拟提交 outputRef
  W->>W: phase=FINISH
  W->>B: v2FinishExecution
  B-->>W: 模拟 agent_run=SUCCEEDED
  W->>W: phase=COMPLETED
  W-->>D: getResult SUCCEEDED
  D->>D: 模拟 SSE 展示助手正文

30 秒内没有 TOOL 信号

flowchart TD
  WAIT[phase=WAIT_TOOL] --> TIMEOUT[Workflow.await 返回 false]
  TIMEOUT --> REVIEW[phase=NEEDS_REVIEW]
  REVIEW --> MARK[BusinessActivitiesImpl.v2MarkNeedsReview]
  MARK --> END[返回 NEEDS_REVIEW]

RunWorkflowImpl 把超时记成待复核。这次返回不表示目录已经列完。

断点打在哪个进程

停在这里调试配置源码
Start、Query、Signaldemo-clientapps/demo-client/.../DemoMain
回放、phase、Workflow.awaitworkflow-workerapps/workflow-worker/.../RunWorkflowImpl
准入、提交、派发、收尾workflow-workerapps/workflow-worker/.../BusinessActivitiesImpl
两轮 modelTurnagent-workerapps/agent-worker/.../ModelActivitiesImpl

RunWorkflowImpl.execute 会在每个新的 Workflow Task 从头回放。Activity 方法只在对应 Worker 里真正执行一次。

同一 Workflow ID 再 Start 一次时，History 按 REJECT_DUPLICATE 拒绝。默认每次调试都会换一个新的 Workflow ID。要看这次拒绝，设置 LEARN_WORKFLOW_ID=joybot/run/42 后连续启动两次 Demo。
